# Shalom · Prototipo integral v0.2

Vista de demostración de una futura plataforma digital para Iglesia Cristiana Shalom.

## Abrir

Una vez habilitado GitHub Pages en **Settings → Pages → Deploy from a branch → main → /(root)**, abrir:

https://danielherrodri.github.io/Shalom-app-demo/

El prototipo es un único archivo `index.html` que incluye diseño, JavaScript y el logotipo proporcionado. No necesita backend para la demostración y puede verse desde Safari, Android o escritorio.

## Funciones de demostración

- Portal de congregación, voluntarios y administración.
- Estacionamiento, capacidad estimada y reservaciones ficticias.
- Familias, tutores y Shalom Kids simulados.
- Eventos e inscripciones.
- Aportaciones y conciliación de prueba.
- Cafetería, proyectos y anuncios.
- Modo Noche/Crema con paleta institucional cobre y fuente Inter (cargada desde Google Fonts si hay conexión).

## Importante

**NO es un sistema en producción.** No existe autenticación segura, base de datos central, sincronización entre dispositivos, cobros reales, envío de correos ni integración con Shalom Kids. Los perfiles y roles son solo de demostración; la información introducida se almacena en el propio navegador. **No introducir información real de menores, contraseñas, CURP, datos bancarios ni aportaciones reales.**

El sistema real de Shalom Kids / Apps Script no ha sido modificado. Para producción se requieren backend, controles de acceso, políticas de privacidad, consentimiento parental y validación operacional.
