# Mockups públicos de Shalom

Demostración estática con datos exclusivamente ficticios, para revisar desde celular o computadora. [Abrir mockups](../design/kids-paneles.html#inicio).

## Vistas

- Inicio y tarjeta prevista para el versículo del día de YouVersion.
- Clase Kids y equipo que imparte cada sesión.
- Reservas de clase, cancelación y conteo para materiales y dulces.
- Coordinación, acompañamiento e incidencias de prueba.
- Conoce al equipo: Cocina, Video, Audio, Kids y Materno.
- Plan mensual de cocina: fechas, platillos, porciones y responsables.
- Eventos Kids: tareas, aceptación y materiales comprometidos/recibidos.
- Libros Kids, pago y recogida como estados separados.
- Avisos y acuerdos para familias.
- Buzón de comentarios de prueba.
- Recogida de menores como recorrido ilustrativo, sin registrar salida.
- Pagos y aportaciones: libros, cooperación de eventos y diezmo voluntario.

En el celular, desliza horizontalmente el menú superior para encontrar las demás vistas. También puedes abrir las secciones mediante el fragmento de enlace, por ejemplo `#cocina`, `#equipo` o `#pagos`.

## Límites de esta publicación

Los cambios son locales y se reinician al recargar. No se registran personas ni asistencia, no se envían comentarios o notificaciones, no existe autenticación real y no se realizan cobros. No escribir datos personales ni credenciales en los formularios. Los precios, personas, fechas y totales son ejemplos; no representan servicios o compromisos vigentes de Shalom.

GitHub Pages no ejecuta la API de Django. La tarjeta de YouVersion ofrece un enlace alternativo; no se publica una App Key ni se inventa un versículo del día. El soporte de imágenes/HTML solo se activa cuando una API del mismo sitio devuelve contenido autorizado. Los botones de cobro no abren una pasarela real.

Publicación limitada a los mockups, recursos y documentación de esta demo. No despliega el servidor ni las integraciones de producción. Para retirar esta versión, revertir el commit de publicación y verificar que GitHub Pages vuelva a completar su despliegue.
